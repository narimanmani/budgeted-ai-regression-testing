# Native TikZ figure sources

These five sources are copied unchanged from the working journal manuscript.
They include the study procedure and four result figures: cold acquisition,
request reuse alongside detection, all primary interaction contrasts, and all
six CG1 comparators. `SOURCE_BINDINGS.json` records their original hashes.

They are LaTeX figure inputs, not standalone documents. They require TikZ,
`arrows.meta` and `positioning`, `booktabs`, and the ACM class definition of
`\Description`; the journal sources supply those dependencies. Figure labels
and caption cross-references refer to the working manuscript. The result CSVs
and static PNG/SVG charts in `../v9/` provide independent browsable values.

These graphics preserve completed observations and introduce no new runs or
policy tuning. The manuscript is a working draft; inclusion does not claim
acceptance or an awarded artifact badge.
