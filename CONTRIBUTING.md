# Working with the artifact

The original studies are closed. Their code, task definitions, source cases,
contracts, observation banks, masks, native outputs and results are preserved
as historical records. The two sealed evidence archives are the authoritative
complete distributions; their hashes identify the exact released bytes.

Documentation corrections and new reproduction tooling can be contributed
without changing those records. Explain a numerical correction with a separate
audit and retain the original value and provenance. Do not replace recorded
outputs with a fresh execution or silently revise the frozen CG1 policy.

For new experiments, create a separately named study with a prospective protocol,
its own environment and request budget, new observations and independent result
tables. Current cases become development evidence when used to tune a new rule.

The offline reproduction scripts verify and reanalyse saved data. Native model
or application executions are a separate activity requiring the recorded assets,
dependencies, hardware and explicit resource allocation. The reproduction scripts
do not launch those services.

Never commit credentials, personal service state, installed environments, model
weights or container images. Preserve upstream copyright and license notices.
